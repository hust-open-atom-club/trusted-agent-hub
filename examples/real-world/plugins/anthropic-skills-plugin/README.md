# anthropic-skills-plugin

A Claude Code plugin built from Apache-2.0 skills vendored from [anthropics/skills](https://github.com/anthropics/skills) at commit `b29e7cf65e5cb78a5ac33d582270551bc74a14eb`.

- License: Apache-2.0 (see `LICENSE.txt`)
- Bundled skills: `skill-creator`, `mcp-builder`, `algorithmic-art`
- Manifest: `manifest.json`
- Plugin metadata: `.claude-plugin/plugin.json`

Install with Trusted Agent Hub CLI:

```bash
npx tah install anthropic-skills-plugin --client claude-code-plugin
```
