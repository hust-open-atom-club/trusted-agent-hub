## 输出要求

请按以下结构输出设计方案：

### 1. 资源模型
- 核心实体及字段
- 实体间关系

### 2. 端点设计
- 每个资源的 CRUD 端点：`METHOD /path`
- 必要的查询参数与分页

### 3. 状态码约定
- 2xx 成功、4xx 客户端错误、5xx 服务端错误的语义

### 4. 错误契约
- 统一错误响应结构（如 `{"code": "...", "message": "..."}`）
- 常见错误场景示例

### 5. 安全与边界
- 认证方式建议
- 输入校验要点
- 幂等性说明（如适用）

## 约束

- 遵循 REST 资源命名规范（复数名词、小写、连字符分隔）
- 明确标注每个端点的请求/响应示例
- 不确定的需求点用「假设：…」标注，不做过度设计
